Hardcoded animation palette is an intentional exception — do not remap fills to semantic text/* or color/actions/* tokens.

#### success

AI-READY ANIMATION: animation/feedback/success — blue circle + white check + confetti. Canvas = composed end-state; implement motion in Lottie/code. Size 320×320. Feedback vocabulary: success. Decorative/celebratory; pair with accessible live text for the outcome.

## Rules

- **vsIcons:** Not DS Icons (*-outline/*-filled)
- **vsIllustrations:** Not static illustration scenes — this family is motion feedback
- **vocabulary:** Use success (deprecated: positive / Positivo)
- **layerHygiene:** Top groups: confetti, badge; badge children: circle, check-path
- **usage:** Full-screen or modal success moments after a completed flow

### Accessibility

Decorative by default when adjacent copy announces success (aria-hidden + live region text). Honor prefers-reduced-motion by showing the static end-state without particle motion.
