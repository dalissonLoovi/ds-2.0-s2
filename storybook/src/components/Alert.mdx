## AI-READY

AI-READY COMPONENT: Alert is an in-flow persistent feedback card used to call attention to status that may require a follow-up action. Use for contextual warnings, successes, info, or danger notices inside pages/forms — not for transient non-blocking messages (use Toast) and not for modal interruption (use Modal). Props: appearance=default|inverse; status=system|info|success|danger|warning (same vocabulary as Toast); title (TEXT); description (TEXT); showDescription (BOOLEAN, default true); showAction (BOOLEAN, default true). Prefer appearance=default on light page surfaces; use appearance=inverse on dark/brand chrome when on-color text is required. status=system is intentional-sparse and has no statusIcon; other statuses compose a DS Icons — Escritório Virtual filled statusIcon at 32px (info-circle-filled, circle-check-filled, alert-circle-filled, alert-triangle-filled) with content-layer icon fills feedback/info|success|danger|warning on \{icon\}-path layers. appearance=default: shell color/background-surface/3 (single fill); title text/primary + body/medium/semi-bold; description text/secondary + body/small/regular; action local Button outline/sm/primary with default light chrome (stroke color/border/1, label text/primary). appearance=inverse: shell fills bottom→top — color/elevation/inverse-3 (base, opacity 1) + color/background-surface/brand @ ~48% opacity (overlay); title text/on-color; description text/on-color-disabled; action outline uses on-color stroke/label for contrast on the dark shell. Composition: statusIcon (when present) + content → text (title + description) + action. Anatomy: vertical stack (icon above content). Pad spacing/150 top, spacing/250 sides/bottom; gap spacing/100; border/radius/400. actionLabel is React-side — in Figma set nested action Button label when showAction=true. Do not use as Toast, Banner, Modal, or inline field validation. Accessibility: role=status for system|info|success; role=alert for warning|danger when urgent; action needs accessible name; decorative status icons aria-hidden when title conveys status. React mapping: Alert(appearance, status, title, description, showDescription, showAction, actionLabel). Code Connect is not configured. Note: Figma VARIANT default for appearance remains inverse (API cannot change VARIANT defaultValue); product instances should set appearance=default on light surfaces.

## Rules

- **intentionalSparse:** status=system publishes no statusIcon
- **appearanceDefault:** Prefer appearance=default on light page surfaces (surface/3 + text/primary|secondary)
- **appearanceInverse:** Use appearance=inverse on dark/brand chrome when on-color text is required
- **figmaDefaultVariant:** Figma VARIANT defaultValue for appearance remains inverse (cannot change via API); set instances to default on light surfaces
- **propWiring:** title / description+showDescription / showAction must be wired on every appearance×status variant (including appearance=default clones)
- **actionLabel:** actionLabel is React-side / nested Button.label — Figma parent TEXT cannot bind to instance sublayer via API; edit nested action label when showAction=true
- **vsToast:** Do not use as Toast — Alert is persistent in-flow; Toast is transient
- **vsBanner:** Do not use as Banner — Banner is full-width page/section feedback on feedback-primary surfaces
- **vsModal:** Do not use as Modal / AlertDialog — Alert does not block the page
- **darkOverlay:** appearance=inverse shell fills bottom→top: color/elevation/inverse-3 (base, opacity 1) + color/background-surface/brand @ ~48% opacity (overlay). Do not reverse the stack (Figma fills[0]=brand@~48% topmost).
- **usage:** Do not use as Toast, Banner, Modal, or inline field validation
- **iconSize:** statusIcon is FIXED 32×32 on info|success|danger|warning
- **iconFillParity:** statusIcon paths use local content-layer feedback/\{info|success|danger|warning\} on \{icon\}-path layers (no remote background-feedback-primary/*).
