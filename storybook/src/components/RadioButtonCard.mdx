## AI-READY

AI-READY COMPONENT: RadioButtonCard is the card/row variation of RadioButton for mutually exclusive choices presented as selectable full-width rows (e.g. Sim/Não). Master demo width is FIXED 343 (mobile exemplar); instances should Fill container. Use when the option needs a full-width tappable surface with radio + label + optional helper description — not only the compact RadioButton. Variants: state=default|hover|focus|disabled; checked=false|true (same axes vocabulary as RadioButton). Props: label (TEXT); description (TEXT, default 'Texto de descrição abaixo do label do radio'); showDescription (BOOLEAN, default true). Composition: card shell + radioControl (20, top-aligned) + labelContent (label body/medium/medium + description body/small/regular); hover adds absolute stateLayer with interactive/hover. Description uses text/secondary (text/placeholder when disabled), matching RadioButton helper text; labelContent gap spacing/050. checked=true uses color/background-surface/1 + color/border-feedback/primary on the shell and color/actions/primary on radioControl (stroke border/width/050). checked=false uses color/background-surface/0 + color/border/1 (radio stroke border/width/025). hover uses an absolute stateLayer fill interactive/hover over the shell. focus uses interactive/focus on the shell stroke. disabled uses color/border/2 + text/placeholder on label and description; disabled+checked radioControl stroke weight matches RadioButton (border/width/025). Shell stroke border/width/012; radius border/radius/400; radioControl radius border/radius/full; pad/gap spacing/200|100. Do not use as Checkbox, Chip, ListItem alone, or Toast. Accessibility: role=radio; aria-checked; aria-describedby when description is shown; group in radiogroup; card surface is the hit target. React mapping: RadioButtonCard(state, checked, label, description, showDescription). Code Connect is not configured.

## Rules

- **vsRadioButton:** Use RadioButtonCard for full-width tappable card/row choices with optional description; use RadioButton for compact non-card text+description options
- **hoverStateLayer:** state=hover: absolute stateLayer fill interactive/hover over shell (clipsContent true); radius matches border/radius/400
- **checkedVisual:** checked=true: shell surface/1 + border-feedback/primary; radioControl actions/primary @ border/width/050
- **uncheckedVisual:** checked=false: shell surface/0 + border/1; radioControl border/1 @ border/width/025 (focus unchecked radio uses border/2)
- **disabledAlign:** disabled+checked radioControl stroke uses border/width/025 (2) — aligned with RadioButton
- **demoWidth:** Master FIXED 343 mobile exemplar; instances should Fill container
- **usage:** Do not use as Checkbox, Chip, ListItem alone, or Toast
- **grouping:** Related options belong in a RadioGroup (role=radiogroup)
- **descriptionParity:** Mirrors RadioButton helper text: description TEXT + showDescription BOOLEAN; body/small/regular; text/secondary (placeholder when disabled); labelContent gap spacing/050
- **composition:** radioControl (20, counterAxisAlign MIN/top) + labelContent (label + description); hover prepends absolute stateLayer
