## AI-READY

AI-READY COMPONENT: ChipClickable is a compact interactive chip used for selectable filters, compact options, removable selections, or contextual actions with low visual emphasis. Usage rule: use ChipClickable when a compact item can be clicked, selected, or removed. Do not use it as a primary button, badge, static tag, checkbox, radio, menu item, alert, or navigation tab. Variant rule: size=sm|md; state=default|hover|pressed|selected|disabled (disabled is intentional sparse — not published for every intent); intent=info|system|success|warning|danger|outline|soft; width=hug|fill. Intentional sparse matrix (published combinations only; soft publishes 16 like outline — no disabled). Intent rule: info|system|success|warning|danger use feedback surfaces. intent=outline is stroke-only on default (color/border/2; interaction fills hover/pressed/selected). intent=soft is the soft actionable chip (Painel Adicionar veículo): default fill color/background-surface/2 + stroke color/border/2; hover/pressed/selected use interactive/hover|pressed|selected with the same border; for that exemplar keep showAvatar=false and showDeleteAction=false; showLeadingIcon=true with local circle-plus-outline or plus-outline; label via TEXT prop (wired on all intents including soft). Label typography: local text style body/small/medium (no remote typography variables). Props: label (TEXT); showLeadingIcon; leadingIcon (INSTANCE_SWAP); showAvatar; showDeleteAction. Token rule: local S2 kebab-case only; chip gaps use spacing/100 where applicable. Accessibility: button or toggle button with aria-pressed when selectable; delete action needs accessible name Remove \{label\}. React mapping: ChipClickable(size, state, intent, width, label, showLeadingIcon, leadingIcon, showAvatar, showDeleteAction). Code Connect is not configured.

## Rules

- **softIntent:** intent=soft: default color/background-surface/2 + color/border/2; interaction states interactive/hover|pressed|selected; Painel Adicionar veículo exemplar
- **softSparse:** soft publishes 16 variants (same sparse as outline — no disabled)
- **outlineVsSoft:** outline = stroke-only default; soft = surface/2 fill + border (do not use ChipTag for actionable Adicionar veículo)
- **labelProp:** TEXT prop label wired on all published variants including soft
- **labelTypography:** local body/small/medium — no remote typography binds

## Token rules

- feedback intents: color/background-feedback-primary/\{intent\} (danger may use interactive/error-surface)
- outline default: color/border/2 stroke only
- soft default: color/background-surface/2 + color/border/2
- soft/outline interaction: interactive/hover | pressed | selected
- text/primary on label
- label text style: body/small/medium
- border/radius/full; spacing/050|100|150 pads/gaps

## Accessibility

Use a button semantic for actions or a toggle button with aria-pressed for selectable chips. Removable chips need a delete action with an accessible name such as Remove \{label\}.
