## AI-READY

AI-READY COMPONENT: SectionHeader — section title row that segments content groups on a screen, with an optional trailing action. Props: emphasis=primary|secondary; showAction=false|true; title (TEXT, default Title). Use emphasis=primary for main page sections (body/large/semi-bold + text/primary). Use emphasis=secondary for less prominent sections, nested groups, overlays, sheets, and secondary surfaces (body/medium/regular + text/secondary). Anatomy: title; when showAction=true, trailing action (local Button variant=text size=sm intent=primary, exposed; showLabel=false, showIcon=true, default icon arrow-narrow-right-outline). On emphasis=secondary, action icon stroke uses text/secondary to match the muted title. Use showAction=false when the section content fits the viewport (e.g. quick-access grid). Use showAction=true for overflow / see-more (e.g. offers carousel). Tokens: primary — text/primary + body/large/semi-bold; secondary — text/secondary + body/medium/regular; spacing/0 (pad/gap); root horizontal SPACE_BETWEEN when showAction=true. Product-theme: action chip binds component/section-header/action/background (EV→surface/0; site-loovi|app-cliente→surface/2) and component/section-header/action/radius (EV→component/button/container/radius/sm; site-loovi|app-cliente→border/radius/full). Do not hardcode surface/0|2 or radius on the action. Do not use as AppHeader, OrganizationHeader, SystemHeader, or as a full Section with content slot — body content is composed separately below. Accessibility: title is the section heading (primary often maps to higher heading level than secondary); action needs an accessible name (aria-label) when icon-only. React mapping: SectionHeader(emphasis, title, showAction, onActionPress). Code Connect is not configured.

## Rules

- **matrix:** Published 4/4 — emphasis × showAction
- **emphasisPrimary:** Main page sections — body/large/semi-bold + text/primary
- **emphasisSecondary:** Overlays, sheets, nested/less relevant groups — body/medium/regular + text/secondary; action icon muted
- **nestedButton:** action is local Button text/sm/primary (exposed) — not remote Material button
- **genericDefaults:** Default title Title (product copy via prop)
- **iconLocal:** Default action icon arrow-narrow-right-outline (EV library)
- **noContentSlot:** Body content is composed separately below — not a Section with slot
- **vsHeaders:** Do not use as AppHeader, OrganizationHeader, or SystemHeader
- **productTheme:** Action fill/radius bind component/section-header/action/* — EV→surface/0 + button radius/sm; site-loovi|app-cliente→surface/2 + radius/full. Do not hardcode those slots.

## Token rules

- emphasis=primary: text/primary + body/large/semi-bold
- emphasis=secondary: text/secondary + body/medium/regular
- emphasis=secondary + showAction: action icon stroke text/secondary
- spacing/0 (pad/gap on all variants, including showAction=true)
- product-theme component/section-header/action/background (EV→surface/0; site-loovi|app-cliente→surface/2)
- product-theme component/section-header/action/radius (EV→button radius/sm; site-loovi|app-cliente→full)
- inherits Button text/sm/primary tokens (action)

## Accessibility
