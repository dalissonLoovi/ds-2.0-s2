## Rules

- **composition:** surface/2 + track (10 steps) + CTA Button secondary; simulator/fleet add blur ellipses; fleet omits meter/track/currency
- **track:** circle-filled + circle-dot-filled (current) + circle-outline; progressFill → color/actions/primary — never ProgressBar/StepProgress/StepperPrimary
- **simulatorTitle:** non-interactive title text (body/small/semi-bold + text/primary) — do not use Link
- **cta:** Button solid/md/secondary label Convidar — exposed nested instance
- **fleet:** multi-vehicle / frotista: fleetTitle + fleetDescription + CTA only; no meter, referralCount, or currency
- **spacingLocalOnly:** use local kebab spacing/* — never remote Title Case Spacing/*
- **noFigmaInteractionVariants:** onInvite is runtime only
- **vsOffer:** Do not use as OfferProductCard
- **vsProgress:** Do not replace track with ProgressBar / StepProgressIndicator / StepperPrimary
