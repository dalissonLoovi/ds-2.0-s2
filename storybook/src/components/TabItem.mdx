## AI-READY

AI-READY COMPONENT: TabItem is the individual tab control used inside a Tabs/TabList pattern to switch between related views in the same page or section. Use variant=primary for filled/elevated tab treatment, variant=secondary for underline tab treatment, and variant=segmented for pill segments inside TabsSegmented. Use state=default, hover, selected or disabled. Focus is intentionally not published on TabItem. Use platform=web or platform=mobile for density. Use appearance=default on standard surfaces and appearance=inverse on inverse/dark/on-color surfaces. Intentional sparse matrix: appearance=inverse is published only for variant=primary + platform=mobile. It is not published for primary+web, secondary, or segmented. variant=segmented: selected fills color/actions/primary + text/on-color; default transparent + text/secondary; hover surface/2 + text/primary; disabled text/placeholder; selectedIndicator hidden; border/radius/full; compose only inside TabsSegmented. Use label for the visible tab text. Use showIcon to toggle the leading icon and leadingIcon (INSTANCE_SWAP) to choose the DS Icons — Escritório Virtual outline icons. Use showAttention and attentionIcon for the optional attention/status affordance. Do not use TabItem as a standalone Button, NavigationItem, Chip, or page-level route link. Compose TabItem only inside a Tabs/TabList wrapper (TabsPrimary, TabsSecondary, or TabsSegmented). Accessibility: wrapper role=tablist; each TabItem role=tab; aria-selected=true only for state=selected; disabled tabs aria-disabled=true; decorative icons aria-hidden when label is visible; keyboard follows Tabs pattern (arrows + Enter/Space). Token rule: prefer DS kebab-case variables (color/actions/primary, color/background-surface/0|2, text/primary|secondary|on-color|placeholder, spacing/050|100|150, border/radius/0|300|full). Avoid Title Case legacy aliases; Border/Icon/20 may remain on icon stroke weight when no local kebab equivalent exists. React mapping: TabItem(variant, state, platform, appearance, label, showIcon, leadingIcon?, showAttention, attentionIcon?).

## Rules

- **composition:** Compose only inside TabsPrimary / TabsSecondary / TabsSegmented — not a standalone Button/NavigationItem/Chip
- **intentionalSparse:** appearance=inverse only for variant=primary + platform=mobile; segmented has no inverse
- **noFocus:** Focus is intentionally not published
- **secondaryIndicator:** selectedIndicator visible only on state=selected for variant=secondary
- **segmentedIndicator:** variant=segmented removes selectedIndicator from the tree; selection is the segment fill
- **usage:** Do not use as Button, NavigationItem, Chip, or page-level route link; use TabsSegmented (not standalone) for pill switchers

## Token rules

- primary/secondary: color/actions/primary, color/background-surface/0|2, text/primary|brand, border/radius/0|300
- segmented: selected color/actions/primary + text/on-color; default text/secondary; hover surface/2 + text/primary; disabled text/placeholder; border/radius/full; spacing/050 pads
- spacing/050 | 100 | 150
- Border/Icon/20 may remain on icon strokeWeight when no local kebab equivalent exists

## Accessibility

role=tab inside role=tablist; aria-selected only when selected; aria-disabled when disabled; decorative icons aria-hidden when label visible.
