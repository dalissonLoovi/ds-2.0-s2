## AI-READY

AI-READY COMPONENT: List is a vertical container that composes one or more ListItem rows through an items SLOT. Use type=plain for an embedded page list surface and type=dropdown for an elevated menu/panel surface. Defaults in the component set: type=dropdown, showScroll=false. Props: items is the SLOT for ListItem instances (DividerHorizontal may separate groups); showScroll toggles the local right-edge scroll affordance when content overflows. Do not put ListActionDropdownItem inside List — use ListItem only. Do not use List as a select field, combobox, navigation drawer, table, or action menu panel; for action menus use ListActionDropdown. type=dropdown is the panel surface only — the external trigger owns aria-expanded / open state. Token rule: local S2 kebab-case + product-theme component/list-action/container/radius on shell corners for both type=plain and type=dropdown (EV→border/radius/200; site-loovi|app-cliente→border/radius/500 — shared with ListActionDropdown). Also color/background-surface/0; type=dropdown elevation DROP_SHADOW color/elevation/5; scroll color/palette/graph + border/radius/full; plus nested ListItem and DividerHorizontal tokens. Switch product-theme mode escritorio-virtual|site-loovi|app-cliente to preview — do not hardcode radius/200 or radius/0 on the List shell. Accessibility: map plain lists to role=list with ListItem as listitem; map dropdown panels to role=menu or listbox depending on selection pattern; keyboard and focus belong to the product implementation; scroll is visual-only. React mapping: List(\{ type, showScroll, children \}) where children map to the items slot. Code Connect is not configured.

## Rules

- **slotListItemOnly:** Compose items SLOT with ListItem only — not ListActionDropdownItem
- **plainVsDropdown:** type=plain = page list surface; type=dropdown = elevated panel surface
- **triggerExternal:** type=dropdown has no internal trigger — parent owns open/aria-expanded
- **vsActionMenu:** For action menus use ListActionDropdown
- **vsSelect:** Do not use as select field, combobox, navigation drawer or table
- **scroll:** Absolute right-edge thumb; visible via showScroll when list overflows
- **defaults:** type=dropdown, showScroll=false
- **productTheme:** Both type=plain and type=dropdown bind shell corners to product-theme component/list-action/container/radius (EV→200; site-loovi|app-cliente→500). Shared with ListActionDropdown — do not hardcode radius/0 or radius/200.
