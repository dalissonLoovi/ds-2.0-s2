## Rules

- **intentionalSparse:** 11/24 published — global: small-centered × default|inverse; super-app: small-centered × default only; specific: all layouts × appearance
- **globalAnatomy:** hierarchy=global: leadingCluster (Avatar exposed + greeting) + trailingActions — not headingContent/back
- **superAppAnatomy:** hierarchy=super-app: leadingActions FIXED 40 (keeper + menu leadingAction sm) | headingContent TextHeader size=small alignment=center FILL | trailingActions HUG (search optional sm + bell sm + profileMenu 48)
- **profileMenuScope:** showProfileMenu / profileMenu published only on hierarchy=super-app
- **painelHomeTrailing:** Painel Home keeps only bell visible; search via showFirstTrailingAction=false by default
- **localTextHeaderOnly:** headingContent must be local TextHeader (3667:4129) — no remote App bar Content / orphan Text header sets
- **globalGreetingCharacteristic:** hierarchy=global keeps dedicated greeting TEXT with body/large/medium — does NOT nest TextHeader
- **trailingSemantics:** firstTrailingAction=search; secondTrailingAction=bell; local Button text/sm icon-only FIXED 40 (keepers + leading/trailing slots FIXED 40; clear minWidth leftovers from md/48)
- **noLegacyAction:** Do not expose or keep a legacy action layer — use leadingAction only
- **painelHome:** appearance=inverse|default + hierarchy=global + layout=small-centered; greeting prop; Avatar + bell
- **vsSystemOrgHeader:** Do not use SystemHeader or OrganizationHeader for mobile app chrome
- **inverseFill:** appearance=inverse root fill binds component/app-header/inverse/background (EV→color/background-surface/inverse-3; site-loovi|app-cliente→color/background-surface/brand) — not color/actions/primary
- **globalTrailingIconStroke:** Manual sync on hierarchy=global trailing Button icons: default → text/primary; inverse → text/on-color
- **inverseTextHeader:** appearance=inverse: nested TextHeader title uses text/on-color (description text/on-color-disabled when shown); default keeps text/primary|secondary
- **smallLayoutFlow:** small|small-centered × specific|super-app: leadingActions + headingContent=TextHeader size=small FILL + trailingActions. Do not bind slot containers' visible to show*; keepers preserve optical center.
- **mediumLargeFlow:** medium|large × specific: headerControls SPACE_BETWEEN FILL (leadingActions FIXED 40 + trailingActions FIXED 40 with 40 keepers) above headingContent; root gap spacing/100 + paddingBottom spacing/150
- **textHeaderSizeMap:** layout→TextHeader size: small|small-centered → size=small (alignment left|center); medium → size=medium; large → size=large. Exemplars showDescription=false; title uses TextHeader typography (small = heading/h3/medium).
- **leadingOpticalCenter:** showAction=false must not collapse the leading slot — leadingSlotKeeper 40 keeps width so headingContent optical center holds while trailingActions stay visible (mirror of trailingSlotKeeper 40).
- **vsBottomSheetHeader:** Do not use AppHeader inside BottomSheet — use BottomSheetHeader
- **productTheme:** AppHeader is mode-aware via product-theme collection (escritorio-virtual | site-loovi | app-cliente). Bind themed slots to component/app-header/* — do not hardcode inverse-3/brand or surface/0|2 on those slots.
- **leadingActionTheme:** leadingAction binds component/app-header/leading-action/background + leading-action/radius (EV: surface/0 + radius/200; site-loovi|app-cliente: surface/2 + radius/full)
- **avatarTheme:** hierarchy=global × appearance=inverse: Avatar fill → component/app-header/avatar/background; user-outline stroke → component/app-header/avatar/icon-color
- **titleThemeTypo:** small|small-centered × appearance=default × hierarchy=specific: title binds component/app-header/title/font-size|line-height|font-weight (EV|site-loovi→heading/h3 + medium; app-cliente→body/medium + regular). textStyleId cleared on those titles.
- **appClienteTitleCase:** app-cliente only: apply text-transform:uppercase in product UI — Figma keeps textCase=ORIGINAL (textCase is not mode-aware). Do not set UPPER on the published variants.
- **slotSizeSync:** After Button size sm migration: leadingSlotKeeper/trailingSlotKeeper and FIXED leadingActions/trailingActions are 40×40 (not legacy 48). trailingActions may have carried minWidth=48 — must clear when resizing.

## Accessibility

Leading actions need accessible labels. Profile and trailing actions should preserve visible focus and keyboard navigation. Profile menu must behave as an accessible menu button. Icon-only search/bell need accessible names.

## Composition

- specific/super-app: TextHeader (headingContent, exposed)
- Button (leadingAction inside leadingActions slot / firstTrailingAction / secondTrailingAction)
- Profile menu (exposed on super-app) + Avatar
